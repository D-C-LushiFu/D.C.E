# UIC 示例

三个 `.uic` 文件加一个曲目脚本，覆盖规范里的绝大部分语法。
它们都被 `tests/run_examples.lua` 真实跑过并断言过结果。

---

## 文件

| 文件 | 演示什么 |
|---|---|
| `ui/主题.uic` | 跨文件超全局 `*#`（常量 / 样式组），超全局里再引用超全局 |
| `ui/主菜单.uic` | `*@` 常量与样式、`*!` 元素组、多元素声明、组广播、`if`/`else`/嵌套条件、读引擎全局 |
| `ui/暂停界面.uic` | 判断链 `why!` / `or!` / `and!` / `no` / `stopWhy`、多值集合、`whynot` 反选、判断链里套 `if` |
| `song_script.lua` | 曲目脚本接入：`require` / 加载 / 取用 / 销毁 |

---

## 怎么用

1. 把 `ui/` 整个目录复制到 `mods/<你的mod>/ui/`
2. 把 `../uic.lua` 复制到 `mods/<你的mod>/scripts/uic.lua`
3. 把 `song_script.lua` 复制到 `mods/<你的mod>/data/<歌曲名>/ui.lua`，
   并把里面的 `MOD_NAME` 改成你的 mod 目录名

加载顺序很重要 —— **先 `主题.uic`，再界面文件**。
因为 `*#` 虽然跨文件，但仍然遵守「先声明后使用」：

```lua
uic.load('ui/主题.uic')     -- 先定义超全局
uic.load('ui/主菜单.uic')   -- 里面 #按钮基底 才解析得到
uic.load('ui/暂停界面.uic')
```

## 几个值得注意的写法

**1. 样式内部是「嵌套叠加」，不是覆盖**

```uic
*# 按钮基底 { scale ? 0.85 }

*@ 按钮样式 {
    #按钮基底       /~ 先叠进 0.85 ~/
    scale ? 0.8     /~ 比例型 → 乘算 → 0.68 ~/
}
```

想要纯覆盖就别嵌套，直接写在元素块里：

```uic
hello.[btn](...) {
    @按钮样式       /~ 标记 ~/
    scale ? 0.8     /~ 直接赋值 → 覆盖上面的结果 ~/
}
```

**2. UIC 是顺序敏感的**

```uic
主菜单按钮.alpha ? 0.95     /~ 组广播 ~/
btn开始.alpha ? 1           /~ 这一句会把 btn开始 盖回 1 ~/
```

**3. 条件里能直接读引擎的 Lua 全局**

```uic
if screenWidth >= 1280 && screenHeight >= 720 { ... }
if curBeat > 16 { ... }
```

单段名字的解析顺序是：UIC 元素 → 引擎全局 → 当前作用域元素的属性。
所以 `why![scale]` 里的 `scale` 会落到「当前元素的属性」上。

**4. 注释可以嵌套**

```uic
/~
hello.[临时](...) /~ 这行注释不会提前结束外层注释 ~/
~/
```
